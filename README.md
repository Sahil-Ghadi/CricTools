## 🚀 Features

### 1. Smart NRR Calculator
- **Live Scenarios**: Calculate exact "chase within X overs" or "restrict within Y runs" scenarios to improve your tournament NRR.
- **Tournament Integration**: Input current tournament stats (Runs Scored, Overs Faced, etc.) for both teams.
- **Detailed Targets**: View a comprehensive table of maximum overs allowed for different score totals to surpass your opponent.
- **Dynamic Updates**: Live predictions update instantly as you change input values.

### 2. PDF Scorecard Parser
- **CricHeroes Support**: Directly upload PDF scorecards exported from CricHeroes.
- **Automated Extraction**: Automatically parses match titles, team scores, and Man of the Match details.
- **Professional Export**: Re-generates a clean, professional scorecard format ready for sharing or printing.
- **Customizable MOM**: Add or edit Man of the Match honors before final export.

### 3. Premium UI & UX
- **Glassmorphic Design**: Modern, translucent interface with subtle background animations.
- **Mobile Optimized**: Fully responsive layout designed for quick use on the field.
- **Micro-animations**: Smooth transitions and interactive feedback for a high-end feel.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [Shadcn UI](https://ui.shadcn.com/) & [Radix UI](https://www.radix-ui.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Tailwind Animate](https://github.com/jamiebuilds/tailwind-merge) & Custom CSS

## 🏁 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sahil-Ghadi/CricTools.git
   cd CricTools
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Build for Production

To create an optimized production build:

```bash
npm run build
npm run start
```
